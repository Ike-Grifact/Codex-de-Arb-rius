# Scripts de manutenção

- `migrate-guides.mjs`: compara os títulos dos HTMLs prioritários com as fontes Markdown correspondentes e prepara os guias com metadados.
- `validate-content.mjs`: verifica fontes, símbolos, slugs e o bloqueio de conteúdo reservado.
- `build-downloads.mjs`: gera cópias Markdown limpas somente de conteúdo público.
- `validate-build.mjs`: inspeciona o site gerado em busca de IDs duplicados, caminhos locais e vazamento de conteúdo reservado.
